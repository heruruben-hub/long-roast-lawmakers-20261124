A [make.fun](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) bounty entry: one satirical sentence roasting lawmakers who would regulate AI, crypto or the internet but cannot convert a file to PDF.

## How it works

`main.py` writes the roast to `/output/entry.txt`, then validates it and reads it back:

- exactly one sentence
- 1–320 characters, not whitespace only
- the file on disk must be byte-for-byte identical to the text written

Run it with:

```sh
python3 main.py
```
